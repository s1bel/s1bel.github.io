Privacy Policy

Last updated: November 9, 2026

Data Access

The application accesses authorized Gmail messages, metadata, and attachments for private automated processing.

Data Usage

Selected message data is used to organize records and may be transferred to an external account explicitly authorized and controlled by the user. Successfully processed messages may be moved to Gmail Trash.

Storage

Processing runs locally. Authentication credentials and processing records may be stored on the user's computer.

Data Sharing

Data is not sold or used for advertising. Information is shared only as necessary for the user's authorized processing.

User Control

The user can revoke application access through Google Account settings and delete locally stored application data.

Google API Compliance

Use of Google user data follows the Google API Services User Data Policy, including Limited Use requirements.
